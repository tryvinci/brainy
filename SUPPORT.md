# Support

Brainy is a developer-preview HTTP service. The fastest way to get unstuck:

1. **Docs** — [docs/README.md](docs/README.md) (Quick Start in the root
   [README](README.md), HTTP API in [docs/api.md](docs/api.md)).
2. **Bugs** — open a GitHub issue with the **Bug report** template. Include
   commands, the Brainy SHA or image tag, and redacted logs.
3. **Features** — **Feature request** template. New ingest/search/recall
   behavior usually needs a fixture.
4. **Security** — do not file a public issue. See [SECURITY.md](SECURITY.md).

Community standards: [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
How to send a change: [CONTRIBUTING.md](CONTRIBUTING.md).
