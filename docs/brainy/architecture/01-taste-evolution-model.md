# Taste Evolution Model

## Stage Model

1. `novice`
- Sparse priors, low pattern library, weak conviction calibration.

2. `competent`
- Functional rule mastery and improved episode-to-pattern abstraction.

3. `sharp`
- Better signal extraction, increased transfer learning across contexts.

4. `elite`
- Stable principle grounding + fast adaptive heuristics + reliable anticipation.

## Triggers
- Stage advancement driven by repeated outcome-calibrated updates.
- Regressions occur when conviction repeatedly fails or signal-noise quality collapses.

## Invariants
- Identity coherence should persist across stage changes.
- Principle integrity must remain intact during rapid adaptation.

## Metrics
- Predictive lift over baseline.
- Time-to-adaptation after regime shift.
- Belief calibration error trend.
- Identity coherence score over long horizon.
