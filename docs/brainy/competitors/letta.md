# Letta Evidence Packet

## Product Claims
- `evidence` Letta positions stateful agents as a core concept and supports memory abstractions including blocks, shared memory, and archival memory. Source: <https://docs.letta.com/guides/core-concepts/stateful-agents/>
- `evidence` Letta Code is described as a memory-first coding harness built on the Letta API. Source: <https://www.letta.com/pricing>

## Memory Model
- `evidence` Memory blocks are structured sections persisted across interactions and always visible without retrieval. Source: <https://docs.letta.com/guides/core-concepts/memory/memory-blocks/>
- `evidence` Blocks have labels, descriptions, limits, optional read-only controls, and can be shared. Source: <https://docs.letta.com/guides/core-concepts/memory/memory-blocks/>
- `inference` Letta blends in-context persistent memory (blocks) with archival retrieval memory.

## Retrieval and Update Loop
- `evidence` Agents can read and update memory blocks through built-in tools; archival memory is a separate concept in docs IA. Source: <https://docs.letta.com/guides/core-concepts/memory/memory-blocks/>
- `inference` Update loop favors agent-mediated memory maintenance over explicit external memory extraction pipelines.
